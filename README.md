# Manual de Buenas Prácticas para Trabajos Universitarios en Grupo

Repositorio colaborativo desarrollado por estudiantes de la **Universidad Valle del Momboy (UVM)** para redactar, organizar y versionar una guía práctica de trabajo académico en equipo utilizando **GitHub** como plataforma de control de versiones documental (sin programación).

## Estructura del Repositorio

* `README.md`: Descripción del proyecto, instrucciones de uso y guía de contribución.
* `CHANGELOG.md`: Registro histórico de versiones y cambios relevantes del manual.
* `documentos/manual_buenas_practicas.md`: Documento principal del manual redactado en Markdown.
* `imagenes/`: Diagramas y recursos visuales de apoyo incluidos en el manual.
* `referencias/guia_apa_7ma_edicion.md`: Guía rápida de citación y referencias bajo Normas APA (7.ª edición).

## Instrucciones de Uso

1. **Lectura en línea:** Haz clic en [`documentos/manual_buenas_practicas.md`](documentos/manual_buenas_practicas.md) para visualizar el manual completo directamente desde el navegador.
2. **Edición externa (opcional):** Si se desea trabajar desde Google Docs o Microsoft Word, se puede descargar el texto, editarlo y exportar la versión actualizada al repositorio.
3. **Obtención del PDF:** Desde el archivo visualizado en GitHub o desde el editor de documentos (Google Docs / Word), selecciona **Archivo > Descargar / Imprimir > Guardar como PDF** para obtener la versión final entregable.

## Guía de Contribución (Flujo sin Consola desde GitHub Web)

1. **Seleccionar tarea:** Entra en la pestaña **Issues** o en el tablero **Projects**, elige la tarea asignada y muévela a la columna *In Progress*.
2. **Crear rama de trabajo:** En el selector de ramas (arriba a la izquierda, donde dice `main`), escribe el nombre de tu rama (`feature/nombre-seccion`) y créala desde `main`.
3. **Editar y guardar cambios (Commit):** Abre el archivo correspondiente en tu rama, pulsa el ícono del lápiz (**Edit this file**), realiza tus aportes y guarda con un mensaje claro en **Commit changes** (ejemplo: *Agrega pautas de citación APA en sección 5*).
4. **Abrir Pull Request (PR):** Ve a la pestaña **Pull requests > New pull request**, selecciona tu rama hacia `main` y vincula el Issue (`Closes #N`).
5. **Revisión entre compañeros:** El otro integrante revisa los cambios en la pestaña *Files changed*, deja comentarios de retroalimentación y aprueba la fusión (**Merge pull request**).
6. **Cierre y versionado:** Tras fusionar, mueve la tarjeta del tablero a *Done* y documenta los cambios relevantes en `CHANGELOG.md` antes de etiquetar la versión (`v1.0`, `v1.1`) en **Releases / Tags**.# manual-trabajos-universitarios
